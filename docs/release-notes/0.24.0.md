## Verticale : visible par OBS, scènes liées et Backtrack

### Le canvas vertical apparaît enfin dans OBS

« VX Vertical » est maintenant enregistré auprès de l'interface d'OBS. Il se
choisit dans **Paramètres → Flux → Canvas supplémentaire**, ce qui ouvre l'accès
au **Dual Format de Twitch** : un seul OBS, deux diffusions, l'horizontale et la
9:16. Le canvas est sauvegardé avec la collection de scènes.

### Scènes verticales liées

La verticale suit automatiquement la scène principale. Activé par défaut,
débrayable par **VX.Stream → Scènes verticales liées**.

### Backtrack vertical

Un tampon de relecture dédié à la verticale, avec son propre encodeur. Il
démarre avec le direct et s'enregistre à la demande, via un raccourci clavier
à régler dans **Paramètres → Raccourcis clavier**. 180 secondes par défaut.

### ⚠️ Si vous aviez déjà composé une mise en page verticale

Elle **n'est pas reprise** : OBS gère ce canvas lui-même désormais, et il
démarre vide. Recomposez la scène verticale une fois, OBS la conservera ensuite
comme n'importe quelle autre scène.

Rien n'est perdu : l'ancienne mise en page reste dans `vertical.json`, dans le
dossier de configuration du plugin.
